# P6 模拟组合

P6 从 P5 冻结预测账本读取股票、评分、信号时间和模型散列。研究账户使用独立目录和 100 万元虚拟现金。不连接券商。相同信号日、成交假设、成本和资金配置适用于六个排序模型与三种持仓策略。

| 策略 | 买入与退出 |
|---|---|
| A 五日持有 | 每日从前一交易日 Top-20 最多补入 4 只，买入满五个交易日后的首个可执行开盘尝试卖出 |
| B 排名缓冲 | 从 Top-20 建仓，仍在 Top-40 的持仓保留。缺榜时保留在持风险和已触发的延迟退出 |
| C 每五日调仓 | 从首个决策交易日起每五个正式交易日使用上一交易日已冻结的 Top-20 |

目标持仓至多 20 只，每笔买入预算最多为开盘时资产的 5%，含费用。价格上涨造成的被动超限保留在持仓账本。普通沪深 A 股按 100 股整手，科创板按 200 股起、1 股递增。北交所已识别代码按 100 股起、1 股递增。不充分辨识的证券或无法确认开盘参考时拒单。已知交易单位参见交易所规则。 [上交所科创板](https://edu.sse.com.cn/tib/qa/) [深交所交易规则](https://docs.static.szse.cn/www/lawrules/rule/trade/W020260424690713155663.pdf) [北交所交易规则](https://www.bse.cn/important_news/200010675.html)

手续费沿用 P3 研究假设。双边佣金万三、最低 5 元，双边过户费万分之 0.1，卖出印花税万五，双边滑点 5 个基点。成交价格使用正式日线开盘价加滑点。当正式涨跌停证据缺失时，以开盘参考价 4% 内带和最小价位作保守代理。无法合理定价、停牌、涨跌停或无法证明卖出可执行时保留拒单和在持头寸。委托级队列与可成交量尚无来源，所有账单标记为模拟成交。

前一日的归档名单用于下一正式交易日的开盘。收益对照为冻结等权池，使用理论开盘再平衡和日内自然漂移。缺价或经济行为不明时，基准回报、组合净值及超额按相应证据留空。非连续市场日期采用数据库可观测正式交易日，整日数据缺失需按交易所日历另查。实际收款和股份到账只接纳已归档且能校验至时点的发行人条款。现金应收、待上市股份、股权登记日与成交现金分开对账。公司行为凭据存于账户的 `settlements` 目录，需官方原 PDF、发布索引和人工核验表，支持 `python -m ashare.p6_settlements --help`。未确认条款不会触发历史持仓删除，事后获知的观察不会重写早间成交。

## 使用方法

```bash
conda run -n py312 python -m ashare.p6_portfolio_run freeze --out "$portfolio"
conda run -n py312 python -m ashare.p6_portfolio_run run \
  --out "$portfolio" --legacy "$legacy" --panel "$panel" --group "$group" \
  --track forward --end "$formal_trade_date"
conda run -n py312 python -m ashare.p6_portfolio_run run \
  --out "$portfolio" --legacy "$legacy" --panel "$panel" --group "$group" \
  --track diagnostic --start 2026-09-23 --end 2026-10-15
conda run -n py312 python -m ashare.p6_portfolio_reconcile "$portfolio/diagnostic-2026-09-23"
```

政策在北京时间 18:00 正式信号边界前冻结，并绑定实际运行代码散列。前瞻账户只接收冻结之后、在发布日当晚及时归档且通过原模型前瞻规则的信号。漏记日保留为空。历史诊断、当日模拟及事后恢复分别标记。输出包括日初与日末现金、净值、风险、持仓、模拟成交、拒单、费用、成本后收益、等权超额和回撤。每个账户日以状态、输入、CSV、Markdown 及摘要散列原子发布。复跑检查已归档日再增量续接。
