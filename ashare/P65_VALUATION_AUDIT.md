# P6.5 组合连续估值核验

独立审计读取冻结组合的 SHA256 日链、当日全部账户、旧持仓和基准状态、实际模拟买单，以及原始同日公司行为观察。退出原因、严格净值和参考净值沿用原账本。若原始见证文件存在，需与该组合日归档的散列一致。原日无见证时，后续同日证据不会改变原记录。

```bash
conda run -n py312 python -m ashare.p65_valuation_audit \
  --portfolio "$portfolio" --legacy "$legacy" --panel "$panel" --out "$new_audit"
```

- `valuation_days.csv` 汇总严格净值缺失、已入账未决权益、受阻买卖和期末关联持仓金额。
- `entitlement_exposures.csv` 逐股、逐日、逐账户保存新增未决权益，以及此前一日、当前收盘的参考持仓金额。跨策略合计会重复同股持仓，金额用于排序，无法据此估算经济损失。
- `coverage_roles.json` 核对旧持仓、旧基准、当日实际模拟买入和新基准成员各自的见证覆盖。冻结 P6 只将此前持仓和此前基准传给公司行为扫描。买入和基准日内阶段没有要求新成分当日的公司行为见证，旧持仓所应得的权益不分配给除权日才买入的新仓。
- `settlement_revision_review.json` 以当前真实时钟重新核对可见发行人公告回执。每次输出单独目录，绑定原日链末端散列、回执散列、来源和实际观察时间。条款冲突单列。单张公告只能证明证实的具体事项，无法认证给定股票的整日覆盖。
- 原账户没有清除未决权益和重写过往订单的入口。未解决的权益使其账户后续新买拒绝，并影响相关股票待卖；旧榜缺失也可能使账面没有买单尝试。补证复核仅供人工查看，独立报告不推出修订后净值。要发布这种净值，需要单独的时点修订制度、完整覆盖、股权登记持仓与明确的会计过账，并保留实际凭据的观察时间。
