# P6.6 统一研究日报

在 ubuntu92 的 py312 环境运行。数据库连接仅查询最新已到 18:00 发布边界的正式行情日和股票代码。预测、经济标签、评价、结算和补丁分数均读取已发布归档。日报区分北京时间生成日、正式行情日和预测日，周末复核使用最近正式交易日。

```bash
bash "$root/mode.sh" ashare.p66_daily_report --root "$root" \
  --legacy "$legacy" --panel "$panel" --out "$root/p66/daily"
```

`latest/daily_research.md` 适合人工阅读，`latest/daily_research.json` 包含归档路径、实际更新时间及散列、逐账户未决事项、原评价摘要和各时间点的资金快照。`latest/research_progress.csv` 逐正式日、逐模型和评价范围累计，覆盖该统一日报开始发布后的日期。最新日的各模型前瞻计数取自原冻结协议的全部可评价历史。账户当日成交、拒单和完整金额请参见 JSON 中的对应账本路径。

- 资金有效覆盖以快照中必需字段齐全且属于当日正式行情的去重股票数除以正式行情股票数。收盘、晚间及盘前版本分别展示。
- OWN 使用该模型的前瞻日期。COMMON7 使用 C 组冻结后的七方法共同股票，交集在标签过滤前确定。分母为零的标签覆盖率为未知，等权股票池不生成 Top-K 榜单。人工复核沿用原协议的 20 个联合有效日及 80% 成熟标签覆盖率，JSON 保留非重叠窗口数及 HAC 误差区间。
- 单独读取当日 `p65/quote-patch-daily` 研究诊断，校验用途、日期及归档散列。其分数不会算入正式预测、前瞻标签或账户。
- 调度状态显示收盘及盘后任务各次真实退出码，并单独读取原夜间任务包装脚本的最后完整轮次。执行中显示尚无完成记录。
- 新修订在 `revisions/<正式日>/<生成时刻>` 下不可变发布；`latest` 以单次重命名切换三个报告和散列清单。同输入、同生成日期的独立重试返回原修订。同日输入更新仅替换累计索引中该交易日的行。归档来源散列校验失败会停止本次发布，上次完整日报仍可用。

日历栏复用独立 P6.6-D 计划与正式行情核验。人工复核对每笔已成熟的前瞻信号检查信号日之后至退出日的日历区间，单列受整日缺行情或未核实日历影响的窗口。其余窗口独立核对原阈值；原冻结结果完整保存在 JSON。P6.6-E 当次前瞻入场日期、独立 V1/V2 评分数量、可用时间和评价路径也随日报记录。
